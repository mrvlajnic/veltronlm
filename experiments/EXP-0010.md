# EXP-0010 — SFT dataset construction

**Date:** 2026-09-30
**Status:** COMPLETE, after a data-quality failure

## Question

Can an instruction-tuning set be built from repository artefacts alone, with no external
teacher model?

## Method

`python -m veltron.finetuning.cli build-data`

## Result

604 examples:

| Category | Count |
|---|---:|
| `grounded_support_qa` | 84 |
| `general_summary` | 135 |
| `general_extraction` | 128 |
| `general_explanation` | 129 |
| `general_classification` | 107 |
| `refusal` | 14 |
| `escalation` | 7 |

583 grounded, 21 refusals, 594 English / 10 Serbian.

## Failure: the first version taught the model that a summary is a list of scanning artefacts

The initial extractive references were drawn from raw Project Gutenberg output, so a
"summary" target looked like:

```
[Illustration]
HEWET'S HOUSEHOLD STORIES
FOR LITTLE FOLKS
ILLUSTRATED BY THE BEST ARTISTS. CINDERELLA
Credit for this e-text: Internet Archive; University of Florida, David Garcia, and the
Project Gutenberg Online Distributed Proofreading Team
```

Training on that teaches the model that a summary is transcription boilerplate — worse than
having no summary task at all.

**Fix:** `clean_for_sft()` removes illustration markers, e-text credits and Gutenberg
headers; `is_boilerplate_heavy()` drops documents whose opening is dominated by them; and
`_sentences()` requires a minimum length and a sentence terminator, which excluded the
fragmented front matter.

Result after the fix: real sentences from real books.

## Interpretation

Three example families are needed, and the third is the one usually forgotten:

1. **Grounded support QA** — extractive from knowledge-base chunks, so a hallucinated
   policy cannot enter the data.
2. **Refusal and escalation** — 21 examples. Without these, SFT teaches that every question
   has an answer.
3. **General instructions** — summarisation, classification, extraction, explanation.

The language imbalance (594 en / 10 sr) is a direct consequence of the corpus, not a bug.
