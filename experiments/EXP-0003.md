# EXP-0003 — Architecture correctness and causality verification

**Date:** 2026-09-30
**Status:** COMPLETE
**Command:** `python scripts/smoke_model.py`, `python scripts/smoke_inference.py`

## Question

Does the Transformer actually implement a causal language model, and is the KV cache
numerically equivalent to a full forward pass?

## Result

| Check | Expected | Measured |
|---|---|---|
| Logits shape | (B, T, V) | (2, 128, 8192) correct |
| Initial loss | ~`ln(V)` = 9.011 | **9.081** |
| Parameters with no gradient | 0 | **0** |
| Parameters with all-zero gradient | 0 | **0** |
| Logit delta at positions **before** an edit | 0 | **0.0** (exactly) |
| Logit delta at the edited position | > 0 | 1.030 |
| Attention probability mass beyond the causal window | 0 | **0.0** |
| KV-cache incremental vs full forward | ~0 | **9.239e-07** |
| Batched (left-padded) vs single-prompt logits | ~0 | **5.513e-07** |
| Batched vs single-prompt token output | identical | **identical** |
| Seeded sampling reproducibility | identical | identical |
| Greedy determinism | identical | identical |
| Save/load output identity | identical | identical |
| Overfit one sequence (120 steps) | loss collapses | **9.165 → 0.064** |
| Learned string preferred over distractor | yes | ppl **1.48** vs **17,984** |

## Interpretation

The architecture is correct. Causality is exact — not approximately, exactly. The KV cache
and left-padded batching are numerically equivalent to unbatched full forwards.

Three real bugs surfaced here and were fixed:

1. **KV cache read uninitialised memory.** `length` was tracked internally and updated only
   on the last layer, so during multi-layer prefill every layer read a length-0 slice. Fixed
   by passing an explicit offset from the model.
2. **Batched generation diverged from single-prompt.** The padding mask was not re-supplied
   on decode steps, so a short row attended to cached pad tokens. Fixed by rebuilding the
   mask per step from each row's pad count.
3. **RoPE positions ignored under left padding.** `forward` now accepts an explicit
   `(B, T)` position tensor.
