# EXP-0002 — Data source reachability probe

**Date:** 2026-09-30
**Status:** COMPLETE
**Command:** `python scripts/probe_data_sources.py`

## Question

Which permissively-licensed corpora are actually reachable from this host?

## Result

14 sources probed; 13 reachable.

## Interpretation

Every planned source is reachable. The probe found a bug before it cost anything: the
single-title Wikimedia response was **81 bytes**, because `prop=extracts` defaults to
`exlimit=1` regardless of how many titles are requested. Adding `&exlimit=20` raised
Wikipedia yield by 20x.

## Next action

Add `exlimit=20` to every `prop=extracts` request. Done.
